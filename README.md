# Calculator Web App

This is a simple web-based calculator application that supports basic arithmetic operations. The project is designed with modular code and includes both model and UI testing.

## 🛠️ Technologies Used

- **Frontend**: HTML, JavaScript  
- **Model Testing**: JUnit4  
- **Automated UI Testing**: Selenium WebDriver  

## ✅ Prerequisites

Before you begin, make sure you have the following installed:

- Python or Python 3  
- Google Chrome browser  
- Chromedriver that matches your Google Chrome version  
  > You can download Chromedriver from: https://developer.chrome.com/docs/chromedriver/downloads

2. Navigate to the directory containing your `chromedriver`:
